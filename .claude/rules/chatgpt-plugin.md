# ChatGPT plugin (`chatgpt/`)

A free, non-monetized OpenAI plugin (ChatGPT and Codex directory) that teaches American mah jongg with the app's free content. Remote MCP server on Cloudflare Workers, stateless streamable HTTP, plus one MCP Apps widget.

- Live: `https://mahj.mahjtrainer.workers.dev/mcp` (workers.dev subdomain `mahjtrainer` on the 2jtest0979 Cloudflare account, free tier; rename it with DELETE then PUT on `/accounts/{id}/workers/subdomain`, since PUT alone refuses an existing one). The plugin's MCP origin is locked once submitted: changing host means a new plugin.
- Content: `npm run content` copies only the free subset from `android/app/src/main/resources/mahj-content.json` (free rooms' non-Plus drills, primer, glossary, reference). Never ship Plus drills here. Fix content errors in `Shared/Content/*.swift`, then `scripts/sync-android-content.sh` and `npm run content` (revert `mahj-parity.json` if only float noise changed). Plugin-only copy lives in `PRIMER_COPY` and `PASS_ALSO` in `src/sessions.ts`.
- Tools: `show_mahjong_lesson`, `start_mahjong_practice`, `read_mahjong_rack` (widget), `define_mahjong_term` and `check_mahjong_answer` (text). All read-only with output schemas. `_meta.widget` carries the widget payload and is hidden from the model. Practice answers live only there, so the model can't give them away; without the widget it checks a typed answer by question id with `check_mahjong_answer`. `read_mahjong_rack` takes an optional `pass` (the Charleston round): blind rounds and the courtesy pass only take tiles that fit nothing.
- `src/rack.ts` reads a dealt rack like a coach: support counts per section (a run tile needs a same-suit neighbor or twin inside a 3-long linked chain within the best 5-wide stretch; quints count jokers toward five), a scored shortlist, a lean only when it is anchored and clear, and a greedy pass with a reason per tile (never jokers or flowers; dead tiles first, then the cheapest fill, never a Singles & Pairs pair). Anchors and tiles to hope for come from the tiles kept after the pass. Racks under 13 tiles only pass dead tiles. `test/rack.test.ts` holds it to the app's 9 hand-match reads and 9 Charleston passes, plus invariants over 1,500 random deals. Sections only; never add card hands.
- `src/tiles.ts` parses what people type: one tile per entry or a whole rack in one string, codes either way round (`5D`, `D5`, `2C2C`), words ("five dots", "north wind", "3 jokers", "1 bird"), `F1`-`F8` and tile emoji. Maps and `Object.hasOwn`, never `in`, so `constructor` is just an unknown word. `rackResult` refuses any rack with an unreadable entry rather than read around it.
- `CARD_YEAR` in `src/rack.ts` is the year the shared content's year examples use. A test fails after April 1 of the next year, as a reminder to update both with the new card.
- Widget: `widget/index.html`, one file, system fonts, no own border (`prefersBorder: true`), jade only on primary buttons, no network calls, so the resource declares an empty CSP (`_meta.ui.csp` and `openai/widgetCSP`). `ui.domain` defaults to the server's own origin. Bump `WIDGET_URI` on breaking changes (hosts cache it; now `trainer-v3`). It always sends `ui/initialize` and falls back to `window.openai` field by field, times out to a Try again card after 10 seconds, validates restored state, and keeps focus and a live region across redraws.
- No upsell and no app link anywhere in tool output, the widget or the listing (the app sells Mahj+; OpenAI bans freemium cross-promotion). The footer is only the NMJL disclaimer. The listing's website, homepage, author and support URLs point at the plugin-only page `docs/chatgpt/index.html`, served at `https://jackwallner.com/ios/mahj/chatgpt/`, never the app's sales page, and nothing in the listing points at GitHub. The page reaches jackwallner.com through the landing-page mirror: `EXTRA_ENTRIES` in `~/portfolio/scripts/sync_ios_pages.py` copies `chatgpt/index.html` and `chatgpt/demo.mp4`, since the sales page does not link them. A new file under `docs/chatgpt/` needs an entry there or a link from one of those pages. Don't call it free in listing copy; that goes in `commerce_description`.
- Privacy: the policy's `#chatgpt` section promises the worker keeps nothing. Keep `[observability] enabled = false` in `wrangler.toml`, no Logpush or tail workers, and no `console` logging in `src/`.
- GET `/mcp` returns 405: a stateless server has no stream to hold open, and an open GET hangs clients.
- Commands: `npm run dev`, `npm test` (or `MCP_URL=https://.../mcp npm test` against live), `npm run check`, `npm run deploy`, `npm run package -- <https url>/mcp` builds `dist/mahj-plugin-<version>.zip`. Each upload needs a new `version` in `plugin/plugin.json`. `node --experimental-strip-types scripts/dump-review.mjs` prints everything the plugin can say, for coach and compliance reviews.
- Submission: platform.openai.com/plugins refuses uploads until the organization is verified. The E3 Fitness LLC org is verified as an individual (Jack, approved 2026-10-22), so the manifest's `author` and `developerName` say Jack Wallner. Business verification needs the LLC's EIN, which is not on file, and Elsa is its only governor. No fee. Platform listing: `plugin_asdk_app_6ada7a0c33c481918f9e1e06df23debc` (platform.openai.com/plugins/manage/...), 1.1.2 uploaded 2026-10-22 (domain verified, MCP configured, no blocking findings; one advisory reminder to review the privacy policy, which already covers data, recipients, retention, removal and contact); the ChatGPT developer-mode connector is a separate app id. The upload dialog builds its file input on click, so an agent opens the dialog, then targets `[role=dialog] input[type=file]` with the file-upload tool. Domain verification: `npx wrangler secret put OPENAI_DOMAIN_CHALLENGE` (never a `[vars]` entry, which overrides the secret) and redeploy; served at `/.well-known/openai-apps-challenge`.
- Testing in ChatGPT: developer mode, Add custom MCP server with the live `/mcp` URL (ZIP upload there cannot reach localhost). After every deploy press Refresh tools on the plugin's settings page; ChatGPT snapshots tool and resource metadata, and a stale snapshot shows "Resource not found". Its first `server/discover` probe gets a 400 and falls back to `initialize`; that is expected. Routing varies run to run: "Quiz me on the American mah jongg tiles." once opened ChatGPT's own quiz instead of the plugin, so a review test prompt that ChatGPT can answer natively names Mahj Trainer.
- Reply length is the model's call: OpenAI's guidelines have no rule on it, and a reviewer flagged sentence counts in tool descriptions as overreach, so the descriptions say what to cover, not how long. Widgets render after the model finishes streaming.
- Review demo: `docs/chatgpt/demo.mp4` (served at `https://jackwallner.com/ios/mahj/chatgpt/demo.mp4`, set as `review.demo_recording_url`), a captioned slideshow built by `python3 chatgpt/scripts/build-demo.py <frames-dir>` from ChatGPT web screenshots of the chat column (the storyboard and frame names live in the script; an agent captures them with the Chrome extension's zoom at scale 1 and `save_to_disk`). Re-record when a tool's UI changes.
- Yearly: the shared content's year examples and `CARD_YEAR` say 2026; update them together with the app when the new card lands each April.

## Claude connector (same worker, `/claude/mcp`)

- Endpoint `https://mahj.mahjtrainer.workers.dev/claude/mcp`; `/mcp` stays ChatGPT's and its tool and widget metadata are frozen as reviewed. `buildServer(env, host)` branches on the path. Claude's copy: widget URI `ui://mahj/claude-v1.html` (the same HTML with `data-host="claude"` and a `color-scheme` meta injected), `prefersBorder: false`, no `ui.domain` (Claude derives its own sandbox origin and rejects a plain origin), CSP `resourceDomains: ["https://assets.claude.ai"]` for Anthropic Sans, no `openai/*` keys, `annotations.title` on every tool (the portal flags its absence), and no description line that steers the model's reply (directory policy).
- In Claude the widget applies the host's style variables, fonts and safe-area insets (`applyHostContext`): structure takes Claude's tokens, tiles and jade stay ours. ChatGPT's copy never runs that branch.
- `/favicon.ico` and `/favicon.png` serve `plugin/assets/icon.png`; Claude shows the origin's favicon beside the connector.
- Listing page `docs/claude/index.html` (served at `https://jackwallner.com/ios/mahj/claude/` via `EXTRA_ENTRIES`), privacy section `privacy-policy.html#claude`, carousel PNGs in `docs/claude/carousel/` (crops of the widget only, 1189px wide, captured from claude.ai with the Chrome extension's zoom at scale 1 and `save_to_disk`). Which section am I leaning toward and what should I pass?"
- Submission: claude.ai/directory/manage, MCP connector, slug `mahj-trainer` (permanent), categories Education and Media & Entertainment, no auth, read only. The portal reads tools from the custom connector's snapshot: after a deploy, Customize > Connectors > Mahj Trainer > ... > Refresh tools list, then reload the draft.
