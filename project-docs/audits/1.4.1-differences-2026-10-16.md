# 1.4.1 vs 1.3.2: every difference, round-two audit (2026-10-16)

Base: e742209 (1.3.2, build 36, what customers have). Compared against main at build 51, then fixed in build 52. Ten Sonnet auditors each owned a slice of the 153 changed app, metadata, site and backend files, plus a coverage sweep. Each slice's findings went to an independent skeptic. Earlier round: [release-experience-2026-10-16.md](release-experience-2026-10-16.md).

## Manual steps before submitting

- App Store Connect > App Privacy: Meta is live, so update the labels in this submission as listed in `project-docs/marketing/meta-ads.md` step 7 (tracking data used for Third-Party Advertising via Meta), and also add what that list leaves out: User Content (the feedback text and question reports, used for Customer Support and App Functionality, not linked to identity, not tracking). The public `docs/asc-submission-checklist.md` is a 1.0-era list and is wrong for 1.4.1.
- Advertising Identifier (IDFA) question at submission: Yes, used to attribute installs and actions to ads (via Meta), with the ATT prompt.
- Review notes (`fastlane/metadata/review_information/notes.txt`) were rewritten for Supabase feedback, Meta/ATT and the challenge event; paste them into the version's App Review Information.
- en-US, en-GB, en-AU and en-CA "What's New" on the version record must be replaced with the repo text (the old record still mentions the removed trial reminder).
