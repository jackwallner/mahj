About these guides

Everything here comes from the same reference material built into Mahj Trainer, written for people who learned the game at someone's kitchen table and want the rules straight before next week. The examples are original teaching hands. The card itself belongs to the National Mah Jongg League, changes every spring, and is the one thing you still need to buy.
