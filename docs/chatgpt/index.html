    Questions

    Does it know this year's card?

    No. The card is copyrighted and changes every April, so Mahj Trainer never quotes its hands. It teaches the sections every card is built from (2468, 13579, 369, Consecutive Run, Like Numbers, Winds & Dragons, Singles & Pairs, Quints and the year hands). Keep your own card next to you for the exact lines.

    How do I type my rack?

    Any way that names each tile. Codes work (5D is 5 Dot, 2B 2 Bam, 7C 7 Crak, N E W S for the winds, RD GD SO for the dragons, F for a flower, J for a joker), and so do words like "five dots", "north wind", "soap" or "3 jokers". Share all 13 tiles for the best read.

    Why did it ask me to fix my rack?

    If it can't read one of the entries, or the rack holds more copies of a tile than a set has, it shows what it read and asks you to correct the rest. A read that skips a tile could tell you to pass the wrong ones.

    Can I name the pass I'm making?

    Yes. Say which pass it is, like "first pass left" or "the courtesy pass", and the advice changes to fit. On the blind-pass rounds it only suggests tiles that fit nothing and leaves the rest for a blind pass.
